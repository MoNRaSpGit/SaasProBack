# Decisiones tecnicas del backend

Fecha de actualizacion: 2026-05-16

## Objetivo

Guardar decisiones tecnicas y operativas que siguen vigentes en el backend SaaS.

## Que entra aca

- decisiones de arquitectura
- decisiones de operacion SaaS
- decisiones de producto compartido que impactan backend
- decisiones duraderas que conviene no rediscutir desde cero

## Que no entra aca

- cambios diarios
- notas de avance
- detalle fino de frontend
- tareas pendientes

Eso va en bitacoras o en la documentacion del frontend correspondiente.

## Relacion con otros documentos

- `architecture/` explica que hacemos
- `operations/bitacora.md` registra que hicimos
- `decisions/` explica por que se eligio una regla duradera
