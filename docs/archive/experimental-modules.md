## Aclaracion

Que un modulo este archivado a nivel de producto no significa necesariamente que no quede ningun resto de codigo o base en el backend.

La regla oficial es:

- no se consideran fuente de verdad actual
- no condicionan decisiones de producto presentes
- si alguno vuelve, renace como producto nuevo sobre la arquitectura actual
